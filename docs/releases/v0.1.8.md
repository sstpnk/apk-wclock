# WClock v0.1.8

## Highlights

- Weather source selection now includes Yandex Weather, Visual Crossing, and Tomorrow.io.
- Settings show provider-specific API key fields only for the selected keyed weather provider.
- Photo rendering now reloads the same selected source after renderer recycle, fixing missing photos after pause/resume and screensaver stop/start.
